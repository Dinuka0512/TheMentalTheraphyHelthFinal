# The Mental Therapy Health System 🧠💻

A JavaFX + Hibernate-based desktop application designed to manage mental therapy health services effectively. This project was developed as part of my software engineering studies at IJSE.

---

## 📌 Features

- 🧑‍⚕️ Therapist Management  
- 🧑‍🦱 Patient Registration & Management  
- 📅 Appointment Scheduling  
- 💵 Payment Management  
- 📊 Dashboard with Statistics  
- 🔐 Secure Login System

---

## 🛠️ Technologies Used

- Java 17
- JavaFX
- Hibernate ORM (v6)
- MySQL
- Maven
- SceneBuilder (FXML UI Design)
- Intellij IDEA

---
